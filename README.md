# LZT Market Search Bot

Умный бот для поиска объявлений и проверки соответствия правилам LZT Market. Поддерживает 7 режимов работы: поиск по ключевым словам, проверку нарушений правил, обнаружение поддельных происхождений.

## ⚡ Возможности

- ✅ 7 режимов поиска (ключевые слова, правила, происхождение, отлеги)
- ✅ Проверка 40+ типов нарушений правил
- ✅ Обнаружение поддельных "личных" аккаунтов
- ✅ Проверка несоответствия происхождения
- ✅ Агрегирование результатов по категориям
- ✅ Graceful shutdown (Ctrl+C) с выводом текущих результатов
- ✅ Встроенный обработчик rate limit (429)
- ✅ Поддержка фильтров по цене и происхождению
- ✅ UI фильтры origin[] и not_origin[]
- ✅ Логирование в `bot.log` и `errors.log`
- ✅ Повторные попытки при rate limit и сетевых ошибках
- ✅ Тесты с `npm test`

## 🆕 Новые функции (v2.3.0)

### Экспорт результатов
После выполнения поиска бот предлагает экспортировать результаты:
- **CSV**: `results_*.csv` — табличный формат для Excel/Google Sheets
- **Excel**: `results_*.xlsx` — полноценный Excel файл с форматированием
- **PDF**: `results_*.pdf` — отчёт с графиками и статистикой

### История проверок
- Автоматическое сохранение всех результатов в локальную БД SQLite (`bot_history.db`)
- Отслеживание изменений в объявлениях между проверками
- Статистика по нарушениям и категориям

### Уведомления в Telegram
- Отправка отчётов о найденных нарушениях в Telegram канал/бота
- Настройка в `config.json`: `telegramToken` и `telegramChatId`
- Детальные отчёты с топ-нарушениями

### Веб-интерфейс
- Простой веб-сервер на Express.js для просмотра результатов в браузере
- Включение: `"enableWebServer": true` в config
- Доступ: `http://localhost:3000` (порт настраивается в `webPort`)

### Многоязычная поддержка
- Локализация интерфейса на русский и английский
- Настройка: `"language": "ru"` или `"language": "en"` в config

### Параллельная обработка
- Опция для одновременной проверки нескольких страниц
- Включение: `"parallelProcessing": true` в config
- Увеличивает скорость, но может вызвать rate limit

## Установка

1. **Node.js 18+** обязателен
2. Скопируйте конфиг:
   ```bash
   cp config.example.json config.json
   ```
3. Заполните `token` (получить на [https://lzt.market](https://lzt.market))

## Запуск

### NPM команды

```bash
npm start              # Запустить бот
npm test               # Запустить все тесты
npm run check-syntax   # Проверить синтаксис JavaScript
npm run lint           # Проверить синтаксис и прогнать ESLint по файлам .js
```

### Прямой запуск

```bash
node bot.js
```

При запуске выберите режим (1-7), сортировку, категории и параметры поиска.

- `1` — поиск по ключевым словам
- `2` — автоматическая проверка всех объявлений
- `3` — проверка всех разделов (категорий) по правилам нарушений
- `4` — проверка неверного происхождения (ищет название с одним происхождением, исключая это происхождение)
- `5` — поиск поддельных личных аккаунтов (в названии "личный", исключает происхождение personal)
- `6` — поиск отлеги по годам в Telegram
- `7` — поиск Social Club в Steam и Epic Games

> При нажатии `Ctrl+C` бот выводит уже найденные результаты и завершает работу.
> Режимы 4-7 имеют фиксированные настройки для оптимизации поиска.

## 📋 Режимы работы подробно

| Режим | Название | Описание |
|-------|----------|---------|
| **1** | Поиск по ключевым словам | Поиск объявлений по фразам с проверкой нарушений |
| **2** | Автоматическая проверка | Проверка всех объявлений в категории на нарушения |
| **3** | Проверка разделов | Проверка выбранных категорий на нарушения, сводная таблица |
| **4** | Проверка происхождения | Ищет несоответствие между названием и происхождением (фиксированные параметры) |
| **5** | Поддельные личные | Ищет "личный" в названии с неправильным происхождением (фиксированные параметры) |
| **6** | Отлеги в Telegram | Поиск объявлений с указанием отложки по годам (фиксированные параметры) |
| **7** | Social Club поиск | Поиск GTA/RDR без доступа к Social Club в Steam/Epic (фиксированные параметры) |

### Режим 4: Проверка неверного происхождения

**Что он ловит:**
- Объявления, где в названии указано одно происхождение, но фактическое происхождение другое
- Пример: название содержит "брут", а происхождение в API указано "personal"

**Проверяемые происхождения:**
- `personal` - Личный (ищет "личный", "personal")
- `brute` - Брут (ищет "брут", "brute")
- `phishing` - Фишинг (ищет "фишинг", "phishing")
- `stealer` - Стилер (ищет "стилер", "stealer")
- `resale` - Перепродажа (ищет "перепродажа", "resale")
- `autoreg` - Autoreg (ищет "авторег", "autoreg")
- `dummy` - Dummy (ищет "пустышка", "dummy")
- `self_registration` - Self registration (ищет "саморегистрация", "self_registration")
- `retrieve_via_support` - Восстановление (ищет "восстановление через поддержку", "retrieve_via_support")

### Режим 5: Поиск поддельных личных аккаунтов

**Что он ловит:**
- Нарушение: **"Продажа под видом личного аккаунта"**
- Объявления с "личный" в названии, но происхождение != personal

**Пример находки:**
```
Название: Personal Steam аккаунт (в названии есть "personal")
Происхождение: brute (неправильное происхождение)
Результат: ❌ НАЙДЕНО - несоответствие происхождения
```

### Режим 6: Поиск отлеги по годам в Telegram

**Что он ловит:**
- Объявления с указанием срока отложки (отлежки, inactive)
- Поиск по фразам: "отлега 12 лет", "отлежка 10 лет" и т.д.

### Режим 7: Поиск Social Club в Steam и Epic

**Что он ловит:**
- Объявления GTA/RDR/Grand Theft Auto "БЕЗ ДОСТУПА К SOCIAL CLUB"
- Поиск в категориях: Steam (1) и Epic Games (12)
- Название: "Personal Steam acc" → Origin: brute ❌
- Название: "Личный Fortnite" → Origin: phishing ❌  
- Название: "Оригинальный acc" → Origin: resale ❌

### 🎯 Режим 6: Поиск отлеги по годам в Telegram

Ищет фразы отлежки с указанием конкретных временных периодов в Telegram.

**Фиксированные настройки:**
- Сортировка: Новые сначала
- Максимум страниц: 1
- Результатов на страницу: 500
- Категория: Telegram (24)

**Поисковые паттерны:**
- "отлежка" / "отлёжка" + года (13, 12, 11, 10... 2)
- "отлега" / "отлёга" + года
- "inactive" + года (низкая активность + период)
- Комбинации с "последний активный", "ласт актив"

### 🎯 Режим 7: Поиск Social Club в Steam и Epic Games

Ищет аккаунты с играми Rockstar (GTA, RDR) без доступа к Social Club.

**Фиксированные настройки:**
- Сортировка: Новые сначала
- Максимум страниц: 1
- Результатов на страницу: 500
- Категории: Steam (1), Epic Games (12)

**Поисковые фразы:**
- "grand (БЕЗ ДОСТУПА К SOCIAL CLUB)"
- "rdr (БЕЗ ДОСТУПА К SOCIAL CLUB)"
- "gta (БЕЗ ДОСТУПА К SOCIAL CLUB)"

> **Совет:** Режимы 4-7 используют фиксированные параметры (новые сначала, 1 страница, 500 результатов) для быстрого поиска специфичных нарушений.

## 📊 Типы нарушений (40+ фраз)

| Категория | Примеры | Причина блокировки |
|-----------|---------|-------------------|
| **Отлежка** | "есть отлежка", "большая отлежка", "ласт актив мой", "низкая активность" | Правило 1.5: нужны конкретные числа (дн/мес/лет) |
| **Реклама** | "крутой", "жир", "топ аккаунт", "под основу", "не восстановят" | Правило 1.4: запрещены неконкретные/оценочные фразы |
| **Почта** | "смени почту", "можно поменять почту" | Правило 1.1: запрещены намеки на смену почты |

### config.json параметры

```json
{
  "token": "ВАШ_JWT_ТОКЕН",
  "apiBaseUrl": "https://prod-api.lzt.market",
  
  "maxPages": 1000,             // Страниц для поиска
  "resultsPerPage": 500,        // Результатов на страницу
  "pageDelayMs": 300,           // Задержка между запросами (мс)
  "categoryDelayMs": 1000,      // Задержка между категориями
  
  "order_by": "pdate_to_down",
  "deduplicateResults": false,  // Убрать дубликаты по ID
  
  "pmin": 0,                    // Минимальная цена (0 = отключено)
  "pmax": 0,                    // Максимальная цена
  
  "checkCategories": ["1", "24"],
  "keywords": ["отлега", "отлёга", "отлежка", "отлёжка", "inactive"]
}
```

### Сортировка (order_by)

- `pdate_to_down` - новые объявления
- `pdate_to_up` - старые объявления  
- `price_to_up` - дешевле
- `price_to_down` - дороже
- `edate_to_up` - недавно отредактированные

## ⚡ Оптимизация и советы

| Проблема | Решение |
|----------|---------|
| **Медленно работает** | ↓ `maxPages`, ↑ `pageDelayMs` снизить до 100 |
| **429 (rate limit)** | ↑ `pageDelayMs` до 1000 мс |
| **Много дубликатов** | Включить `"deduplicateResults": true` |
| **Нужны все категории** | В режиме 3/5/6 выбрать `all` при запросе |
| **Нужны конкретные цены** | Заполнить `pmin` и `pmax` в config |
